# Support

## Community help

Questions, bug reports and feature requests go through
[GitHub issues](https://github.com/peacefulstudio/canton-dotnet-sdk/issues).

## Security

Do not file a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Commercial support

Peaceful Studio maintains this SDK and works with teams building on Canton: Daml smart contract and application development, integrating existing .NET systems with a Canton ledger, and operating validator nodes. Write to info@peaceful.studio or visit https://peaceful.studio.
